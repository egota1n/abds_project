participant Consumer

User -> API: POST /events
API -> ClickHouse: INSERT raw.events

RabbitMQ -> Consumer: deliver messages
Consumer -> API: POST /events (batch)
API -> ClickHouse: INSERT raw.events

== Analytics ==
Airflow -> ClickHouse: ETL raw → dwh → mart
Superset -> ClickHouse: SELECT marts
